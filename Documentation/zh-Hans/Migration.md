先固定数据排序、颜色、选择、空状态和容器尺寸。把业务模型映射为稳定的图表数据，同时展示旧图与软件包视图，检查平面和立体模式。选择状态继续由接入应用管理。验证模式切换、滚动和无障碍后，再删除旧渲染器。

## 检查清单

- [ ] 在接入应用中先解析本地化标签和语义颜色，再构造图表数据。
- [ ] 给图表一个有限高度。它填满父容器提供的槽位。
- [ ] 使用稳定 ID 往返 `selectedID` 与选择回调。
- [ ] 标签拥挤时设置 `flatMinimumGroupWidth`，并为 Canvas 提供完整无障碍说明。
- [ ] 执行软件包测试
- [ ] 执行接入应用回归测试
- [ ] API 参考 · 变更记录
