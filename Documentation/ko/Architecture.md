## 개요

하나의 데이터 모델을 두 렌더러가 공유합니다. 바깥쪽 `ZStack`은 평면 차트와 입체 차트를 모두 유지하고 현재 모드에 따라 투명도와 탭 수신 여부만 바꿉니다. 따라서 모드를 전환할 때 주변 레이아웃이 움직이지 않습니다. 좌표 계산은 SwiftUI 렌더링과 분리되어 있어 단위 테스트로 검증할 수 있습니다.

## 동작 보장

- 두 표시 방식에서 같은 데이터 모델 사용
- 모드를 전환해도 주변 레이아웃 유지
- 선택 상태와 선택 해제는 앱에서 관리
- 입체 차트의 드래그, 시점 초기화, 탭 판정
- 항목 수에 따라 평면 차트를 가로로 스크롤

## 책임 경계

이 패키지는 앱에서 준비한 데이터를 그리는 일만 담당합니다. 데이터 집계, 현지화, 테마 결정, 선택 상태 저장, 범례, 막대를 눌렀을 때의 화면 이동은 앱에서 구현해야 합니다.

차트는 상호작용에 따라 `onSelect`와 `onClearSelection`을 동기적으로 호출합니다. 선택 상태를 소유하거나 변경하지는 않습니다. 통합 앱이 상태를 갱신할지와 갱신 방법을 결정합니다.
