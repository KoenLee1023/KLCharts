# KLCharts 마이그레이션

> <span lang="ko">[English](../../README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [日本語](../ja/README.md) · [한국어](../ko/README.md)</span>

먼저 데이터 순서, 색상, 선택 상태, 빈 화면, 컨테이너 크기를 테스트로 고정합니다. 도메인 모델을 안정적인 ID가 있는 차트 데이터로 변환한 뒤 기존 화면과 나란히 놓고 두 모드를 비교합니다. 선택 상태는 계속 앱에서 관리하고 전환, 스크롤, 접근성을 확인한 다음 기존 렌더러를 삭제합니다.

## 체크리스트

- [ ] 표시 문자열과 의미에 맞는 색상을 앱에서 결정한 뒤 차트 데이터를 만듭니다.
- [ ] 차트에는 명시적인 높이를 지정합니다.
- [ ] 안정적인 ID로 `selectedID`와 선택 콜백을 연결합니다.
- [ ] 항목이 많으면 `flatMinimumGroupWidth`를 조정하고 Canvas에는 내용을 설명하는 접근성 정보를 제공합니다.
- [ ] 패키지 테스트 실행
- [ ] 통합 앱 회귀 테스트 실행
- [ ] API 레퍼런스 · 변경 기록
