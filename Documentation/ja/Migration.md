# KLCharts 移行

> <span lang="ja">[English](../../README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [日本語](../ja/README.md) · [한국어](../ko/README.md)</span>

最初に、データの順序、色、選択状態、空の表示、コンテナの寸法をテストで固定します。次にドメインモデルを安定した ID を持つ表示データへ変換し、既存の画面と並べて2つのモードを比較します。選択状態は引き続きアプリ側で管理し、切り替え、スクロール、アクセシビリティを確認してから旧実装を削除します。

## チェックリスト

- [ ] 表示用の文字列と意味に対応する色をアプリ側で決定し、データを作成します。
- [ ] チャートには明示的な高さを指定します。
- [ ] 安定した ID を使い、`selectedID` と選択時のコールバックを接続します。
- [ ] 項目が多い場合は `flatMinimumGroupWidth` を調整し、Canvas には内容を説明するアクセシビリティ情報を設定します。
- [ ] パッケージのテストを実行
- [ ] 組み込み先アプリの回帰テストを実行
- [ ] API リファレンス · 変更履歴
